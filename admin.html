✏️ 新增版本 编辑中

建议使用 v主.次.修订 格式，如 v1.2.0
版本号不能为空，且同一项目内不可重复
默认填入当前时间（精确到秒），可手动修改；不能晚于此刻
请填写有效的日期时间（不能晚于当前时刻）
小技巧：以 - 开头的条目会自动提取为「更新日志」显示在客户端
在网盘中「分享」文件后，复制分享链接粘贴到这里
请填写下载链接
填写了下载链接时必须填写提取码
① 保存版本 = 存进本机草稿，只有你自己看得到
② 发布到网站 = 推送到 GitHub，约 1~2 分钟后所有人可见

GitHub 直推（一键保存）
🔑
Token 怎么获取
GitHub 右上头像 → Settings → 左下 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  • Repository access：只勾 Only select repositories → 选中本仓库
  • Permissions：只给 Contents → Read and write，其他一律不开
  • Expiration：建议 30~90 天，到期重新生成
Token 只保存在你自己这台浏览器的 localStorage 里， 不会写入仓库、不会提交到 git、不会发给任何第三方。
